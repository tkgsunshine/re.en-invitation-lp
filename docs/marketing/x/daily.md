# 毎日のチェックリスト

| 【投稿】 | 【返信】 | 【フォロー】 | 【いいね】 |
|---|---|---|---|
| **3本**（空いた時間に。MBTIランキング1本＋他の4種類から2本） | **15〜30件（上限30）**＋自分の投稿への返信（1時間以内） | **10〜30人（上限30）** | **30件ほど** |

- **コラム紹介の投稿**: 本文をコピーして投稿するだけ（リンクは本文の末尾。返信は付けない）→ ホームで「投稿した」
- **やらない**: 自動ツール／同じ文のコピペ返信／返信にURL・宣伝／出会い目的・不倫の誘い・成人向けのアカウント／他社の名指し／連続10件以上の返信
- **毎週日曜の夜**: 【確認】 Xのアナリティクス（表示回数・プロフィール訪問・リンククリック）と、Vercel Analytics の `t.co` を見て、数字をチャットで伝える
