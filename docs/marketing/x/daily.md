# 毎日のチェックリスト（約40分）

詳しい理由と数字は、「運用戦略」を見る。

## 起床後〜昼前（10〜12時）
- [ ] 検索ワードで、返信対象を探して、返信5〜10件（宣伝・URLなし）

## 昼（12:30）
- [ ] 「投稿待ち」の上から1本を投稿 → スレッド型なら、続けて返信1・返信2 → ホームで「投稿した」
- [ ] 自分の投稿についた返信に、返信（1時間以内）
- [ ] フォローを5〜10人

## 午後（13〜17時・隙間時間）
- [ ] 返信を5〜10件（連続10件以上はしない）

## 夕方（18:00）
- [ ] 「投稿待ち」の上から1本を投稿 → 返信1・2 → ホームで「投稿した」
- [ ] 返信を3〜5件、返信への返信

## 夜（21:30〜）
- [ ] 「投稿待ち」の上から1本を投稿 → 返信1・2 → ホームで「投稿した」
- [ ] 返信を5〜10件、フォロー5〜10人、返信への返信

## スレッド型の投稿の手順
1. 本文をコピーして、Xに投稿
2. 投稿した自分のポストを開いて、返信1をコピー → 返信として投稿
3. 返信1の下の「返信」で、返信2（コラムのURL）を投稿
4. ホームに戻って「投稿した」

## 守る数字
| 項目 | 第1週 | 第2週以降 | 上限 |
|---|---|---|---|
| 投稿 | 3本/日（昼・夕方・夜） | 3本/日 | — |
| 返信（他人の投稿へ） | 10〜20件/日 | 15〜30件/日 | **30件/日**。連続10件以上はしない |
| フォロー | 10人/日 | 15〜20人/日 | 30人/日 |
| いいね | 20件/日 | 30件/日 | — |

## やらないこと
- 自動のフォロー・いいね・返信ツール
- 同じ文面のコピペ返信、返信にURLや宣伝を入れる
- 出会い目的・不倫の誘い・成人向けのアカウントへの返信・フォロー
- 他社アプリの名指しの比較・誹謗

## 毎週1回（日曜の夜・15分）
- [ ] Xのアナリティクスで、表示回数・プロフィールへのアクセス・リンクのクリックを見る
- [ ] Vercel Analytics の Referrers で、`t.co` の訪問者数を見る
- [ ] 数字をAI社員（チャット）に伝える → 運用戦略と投稿案を更新
