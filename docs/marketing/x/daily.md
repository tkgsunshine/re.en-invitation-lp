# 毎日のチェックリスト（約40分）

詳しい理由と数字は、「運用戦略」を見る。

## 起床後〜昼前（10〜12時・10分）
- [ ] 検索ワードで、返信対象を探して、返信を3〜5件（宣伝・URLなし）

## 昼（12〜13時・10分）
- [ ] 「投稿待ち」から1本コピーして、Xに投稿（12:30ごろ） → ホームで「投稿した」
- [ ] 自分の投稿についた返信に、返信（1時間以内）
- [ ] フォローを5〜10人（悩み・関心が近い人、発信力のある人）

## 夕方（17:30〜19時・10分）※第2週以降。余裕があるときだけ
- [ ] 「投稿待ち」から1本コピーして、Xに投稿 → ホームで「投稿した」
- [ ] 返信を3〜5件

## 夜（21:30〜24時・20分）
- [ ] 「投稿待ち」から1本コピーして、Xに投稿 → ホームで「投稿した」
- [ ] 返信を5件
- [ ] フォローを5〜10人
- [ ] 自分の投稿についた返信に、返信

## 守る数字
| 項目 | 第1週 | 第2週以降 | 上限 |
|---|---|---|---|
| 投稿 | 2本/日（昼・夜） | 2〜3本/日（昼・夕方・夜） | — |
| 返信（他人の投稿へ） | 5〜8件/日 | 10〜15件/日 | 連続10件以上はしない |
| フォロー | 10人/日 | 15〜20人/日 | 30人/日 |
| いいね | 20件/日 | 30件/日 | — |

## やらないこと
- 自動のフォロー・いいね・返信ツール
- 同じ文面のコピペ返信、返信にURLや宣伝を入れる
- 出会い目的・不倫の誘い・成人向けのアカウントへの返信・フォロー
- 他社アプリの名指しの比較・誹謗

## 毎週1回（日曜の夜・15分）
- [ ] Xのアナリティクスで、表示回数・プロフィールへのアクセス・リンクのクリックを見る
- [ ] Vercel Analytics の Referrers で、`t.co` の訪問者数を見る
- [ ] 数字をAI社員（チャット）に伝える → 運用戦略と投稿案を更新
