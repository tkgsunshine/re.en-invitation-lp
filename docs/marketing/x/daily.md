# 毎日のチェックリスト（1日3本投稿・返信は可能な限り）

詳しい理由と数字は、「運用戦略」を見る。

**色の見方**: 【投稿】 自分の投稿　【返信】 他人の投稿への返信・自分の投稿への返信　【フォロー】 フォロー　【いいね】 いいね　【検索】 返信対象の探索　【確認】 数字の確認

## 起床後〜昼前（10〜12時）
- [ ] 【検索】 検索ワードで、返信対象を探す
- [ ] 【返信】 他人の投稿に返信を5〜10件（宣伝・URLなし）
- [ ] 【いいね】 共感できる投稿に、いいねを10件ほど

## 昼（12:30）
- [ ] 【投稿】 「投稿待ち」の上から1本を投稿（スレッド型なら、続けて返信1・返信2）→ ホームで「投稿した」
- [ ] 【返信】 自分の投稿についた返信に、返信（1時間以内）
- [ ] 【フォロー】 5〜10人をフォロー

## 午後（13〜17時・隙間時間）
- [ ] 【検索】 検索ワードで、新しい投稿を探す
- [ ] 【返信】 5〜10件（連続10件以上はしない）
- [ ] 【いいね】 10件ほど

## 夕方（18:00）
- [ ] 【投稿】 「投稿待ち」の上から1本を投稿 → ホームで「投稿した」
- [ ] 【返信】 他人の投稿に3〜5件。自分の投稿についた返信にも返信

## 夜（21:30〜）
- [ ] 【投稿】 「投稿待ち」の上から1本を投稿 → ホームで「投稿した」
- [ ] 【返信】 他人の投稿に5〜10件。自分の投稿についた返信にも返信
- [ ] 【フォロー】 5〜10人をフォロー
- [ ] 【いいね】 10件ほど

## スレッド型の投稿の手順
1. 【投稿】 本文をコピーして、Xに投稿
2. 【返信】 投稿した自分のポストを開いて、返信1をコピー → 返信として投稿
3. 【返信】 返信1の下の「返信」で、返信2（コラムのURL）を投稿
4. ホームに戻って「投稿した」を押す

## 守る数字
| 行動 | 1日の目安 | 上限 |
|---|---|---|
| 【投稿】 | 3本（昼・夕方・夜） | — |
| 【返信】 | 15〜30件 | **30件**。連続10件以上はしない |
| 【フォロー】 | 10〜20人 | **30人** |
| 【いいね】 | 30件ほど | — |

## やらないこと
- 自動のフォロー・いいね・返信ツール
- 同じ文面のコピペ返信、返信にURLや宣伝を入れる
- 出会い目的・不倫の誘い・成人向けのアカウントへの【返信】【フォロー】
- 他社アプリの名指しの比較・誹謗
